3. Quality Control & Sanity Checks

Before running statistics, we prepare the DESeq2 dataset (~ line + condition to account for donor differences), verify sample sex using Y-chromosome genes, check macrophage markers, and remove lowly expressed genes.

# set factor levels ("naive" is our control)
colData(se)$condition <- factor(colData(se)$condition, 
                                levels = c("naive", "IFNg", "SL1344", "IFNg_SL1344"))
colData(se)$line <- factor(colData(se)$line)
colData(se)$sex  <- factor(colData(se)$sex)

# round counts to integers (required by DESeq2)
counts_rounded <- round(assay(se, "counts"))

# DESeq2 object
dds <- DESeqDataSetFromMatrix(
  countData = counts_rounded,
  colData   = colData(se),
  design    = ~ line + condition
)
converting counts to integer mode
rowData(dds)$gene_name <- rowData(se)$gene_name

4. Exploratory Data Visualization (PCA)

We apply Variance-Stabilizing Transformation (vst) so highly expressed genes do not dominate the plot, and visualize how samples group together in a Principal Component Analysis (PCA).

# transform counts with vst
vsd <- vst(dds, blind = TRUE)

pcaData <- plotPCA(vsd, intgroup = c("condition", "line", "sex"), returnData = TRUE)
using ntop=500 top features by variance
percentVar <- round(100 * attr(pcaData, "percentVar"))

ggplot(pcaData, aes(x = PC1, y = PC2, color = condition, shape = sex)) +
  geom_point(size = 3.5, alpha = 0.85) +
  labs(
    title = "PCA of Human iPSC-Derived Macrophages",
    x     = paste0("PC1: ", percentVar[1], "% variance"),
    y     = paste0("PC2: ", percentVar[2], "% variance"),
    color = "Condition",
    shape = "Donor Sex"
  ) +
  theme_bw()

↑ you can clearly see that the conditions are clearly separated and have a clean distribution with the donor sex

Synergy Iteraction Model (~ line + IFNg + Salmonella + IFNg : Salmonella)

we are trying to test if the IFNg + Salmonella equals just a summed effect or if there is actually an interaction between them that can change something in gene expression (synergy or saturation)

# set factor levels for IFNg and Salmonella, no is reference

colData(dds)$Salmonella <- factor(colData(dds)$Salmonella, levels = c("no", "yes"))
